# NEXUS ECHO teaser v2 - audio licenses and provenance

Summary: **nothing external was used.** Every sound is either synthesised from scratch by the generator in `scripts/audio2/` for this project, or is the project's own recording `public/audio/p24b-rahal.mp3`. No sample, loop, preset, impulse response or third-party code was downloaded or incorporated. No attribution is owed to anyone.

## External library connectivity test

Run from the build sandbox, standard HTTPS through the sandbox's egress proxy, 8 s timeout, on 2026-10-04:

| Host | Result |
|---|---|
| freesound.org | `curl: (56) CONNECT tunnel failed, response 403`, HTTP status 000. The proxy reported "connect_rejected (the egress proxy denied the CONNECT (organization policy) or could not reach the destination)" |
| pixabay.com | same: 403 on CONNECT, status 000, `connect_rejected` |
| mixkit.co | status 000 (blocked: no response through the proxy) |
| commons.wikimedia.org | status 000 (blocked: no response through the proxy) |

Conclusion: all four candidate sound libraries were unreachable, so there was nothing to download and licence-check, and the plan was original synthesis. No attempt was made to bypass the proxy. No external audio, no external presets, no external impulse responses, and no third-party code were used. If the team later adds a library sound, it must get its own row here with the exact URL, licence and attribution text.
